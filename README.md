# team-store

Учебный командный проект курса RSSchool (fullstack-engineering):
**интернет-магазин электроники**.

Каталог гаджетов с поиском, фильтрами и сортировкой, корзина с изменением
количества и промокодом, страница «О нас».

## Возможности

- **Каталог** — карточки товаров, поиск по названию, фильтр по нескольким
  категориям и диапазону цены, сортировка по цене, пагинация.
- **Наличие** — товар с нулевым остатком показывается с пометкой
  «Нет в наличии», кнопка неактивна.
- **Корзина** — добавление и удаление, изменение количества (не выше остатка),
  подсчёт суммы в копейках, промокод `SALE10` (−10%), сохранение в
  `localStorage`, счётчик товаров в шапке.
- **Данные** — публичный API [DummyJSON](https://dummyjson.com) или локальные
  mock-фикстуры (переключается переменной окружения).
- **Адаптивность** — от мобильного экрана до десктопа.

## Структура проекта

```text
src/
  main.ts                  # точка входа: токены, стили, запуск UI
  config/                  # настройки и константы
    constants.ts           # название, категории, сортировка, размер страницы, ссылки
    env.ts                 # источник данных (mock/api) и базовый адрес API
    routes.ts              # маршруты и их хэши
    navigation.ts          # пункты меню
    team.ts                # команда и стек
    promo-codes.ts         # промокоды
    storage.ts             # ключ корзины в localStorage
  domain/                  # типы предметной области
    product.ts             # Product (priceCents, stock), Category
    cart-item.ts
    cart-line.ts
    cart-totals.ts
  data/                    # источники данных
    api/                   # DTO, маппер, загрузка (mock/api), сборка URL
    fixtures/              # 12 реальных товаров DummyJSON
    mock/                  # getMockProducts()
  services/                # логика без разметки
    router.ts              # хэш-роутер
    catalog.ts             # фильтрация и сортировка
    pagination.ts          # постраничный вывод
    cart-calculations.ts   # чистые расчёты корзины
    cart-storage.ts        # сохранение в localStorage
    cart-store.ts          # состояние корзины и подписки
  ui/
    components/            # компоненты: папка на компонент, ts + css
    pages/                 # страницы приложения
    app.ts
    dom.ts
    format.ts
    icons.ts
    header.ts
    footer.ts
  styles/
    tokens.css             # дизайн-токены (CSS-переменные)
    reset.css              # нормализация
    main.css               # база, каркас, шапка, подвал, кнопки, адаптив
tests/                     # unit-тесты (Vitest)
index.html                 # оболочка: #app и подключение main.ts
public/                    # статика «как есть» (favicon)
```

Правила разработки, стиль кода и договорённости по слоям — в
[CONTRIBUTING.md](CONTRIBUTING.md).

## Запуск

Требования: Node.js 20+ (рекомендуется 22), npm.

```bash
npm install
npm run dev       # dev-сервер с HMR
npm run build     # типизация + сборка в dist/
npm run preview   # просмотр собранной версии
npm test          # unit-тесты
npm run lint      # ESLint
npm run format    # Prettier
```

### Переменные окружения

Скопируйте `.env.example` в `.env` и при необходимости измените:

| Переменная          | Значения       | По умолчанию               |
| ------------------- | -------------- | -------------------------- |
| `VITE_DATA_SOURCE`  | `mock` / `api` | `mock` в dev, `api` в prod |
| `VITE_API_BASE_URL` | адрес API      | `https://dummyjson.com`    |
